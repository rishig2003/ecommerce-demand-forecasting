# E-Commerce Uncensored Demand Forecasting & What-If Simulator

An end-to-end e-commerce demand forecasting pipeline and full-stack web application that predicts uncensored customer demand (`true_demand`) and prevents historical stockouts from causing recurring inventory under-orders.

---

## Why Uncensored Demand Matters

When a high-demand product runs out of stock, recorded sales (`units_sold`) get artificially capped by available inventory—or drop to `0`. Training a standard forecasting model on `units_sold` teaches it to mistake supply shortages for weak customer demand, leading to chronic under-ordering and lost revenue.

This project addresses that failure mode by:
1. **Validating accounting & stockout invariants** at ingestion (`revenue = net_units * price`, `net_units = units_sold - returns`, `true_demand >= units_sold`).
2. **Engineering leak-free time-series features** using `.shift(1)` prior to rolling aggregations so current-week outcomes never leak into training.
3. **Evaluating business impact alongside error metrics** using out-of-time chronological splits, **WAPE**, **forecast bias**, **unmet demand**, **excess inventory**, and **dollar-denominated stockout revenue risk**.
4. **Serving live forecasts & simulations** through a **Flask** backend and **Tailwind CSS** dashboard.

## Quickstart

### 1. Install Dependencies
```bash
uv sync
```

### 2. Run Unit Tests
```bash
uv run pytest -v
```

### 3. Train the Model & Generate Reports
```bash
uv run python main.py
```

This generates:
* `data/processed/features.parquet`
* `models/lgbm_demand_model.txt`
* `reports/metrics.json`

### 4. Launch the Flask Dashboard
```bash
uv run python app.py
```

Open **`http://127.0.0.1:5000`** in your browser to explore:
* **Validation KPIs:** WAPE, RMSE, MAE, projected stockout revenue loss, excess inventory units, and forecast bias.
* **Stockout Recovery Table:** Side-by-side comparison of `units_sold` vs. `true_demand` vs. `predicted_demand` during stockout weeks.
* **What-If Demand Simulator:** Live price and promotion (`on_promo`) sensitivity testing backed by `/api/simulate`.

## Future Improvements

* **Asymmetric / Quantile Loss:** Tune quantile objectives (e.g., $\alpha > 0.5$) for high-margin SKUs where stockout opportunity cost outweighs holding cost.
* **Safety Stock Buffer:** Combine point forecasts with rolling demand volatility to set dynamic reorder points.
* **Automated Drift Monitoring:** Track incoming feature distributions and rolling WAPE across SKU categories and cold-start launches in production.
